Public Hearing Service

ศูนย์รับฟังความคิดเห็นสภานักเรียน

แจ้งเรื่องร้องเรียน เสนอแนะ หรือติดตามความคืบหน้า

ข้อตกลงการใช้งานระบบ

1. ระบบนี้จัดทำขึ้นเพื่อรับฟังเสียงจากนักเรียน บุคลากร ศิษย์เก่า และผู้ปกครอง เพื่อนำมาพัฒนาโรงเรียนและบริการของสภานักเรียน

2. การแจ้งข้อร้องเรียนจำเป็นต้องระบุข้อมูลที่เป็นจริง เพื่อประโยชน์ในการตรวจสอบและประสานงานแก้ไขปัญหา

3. โปรดใช้ถ้อยคำที่สุภาพ สร้างสรรค์ และไม่หมิ่นประมาทบุคคลอื่น

4. กรณีผู้แจ้งเลือก "ไม่ยินยอมเปิดเผยชื่อ" ระบบจะซ่อนชื่อของท่านไม่ให้แสดงในหน้ารายการสาธารณะโดยเด็ดขาด

ข้อมูลส่วนบุคคลของผู้แจ้งจะถูกเก็บรักษาเป็นความลับสูงสุดตามมาตรฐานการคุ้มครองข้อมูลส่วนบุคคล

แบบฟอร์มแจ้งเรื่อง

REGIS Security Check
